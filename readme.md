# 🧩 JavaScript Basics Archive

This repository is a small collection of projects I built while learning the fundamentals of **JavaScript**, **DOM manipulation**, and **browser interactivity**.  
Each project was a hands-on way to strengthen my problem-solving and logic-building skills — from simple games to dynamic UI functionality.

---

## 🚀 Live Projects

| Project | Description | Live Demo |
|----------|--------------|-----------|
| 🎮 **Tic Tac Toe** | A two-player Tic Tac Toe game built using JavaScript DOM logic. It detects wins, draws, and resets automatically for the next round. | [Play Here](https://javascript-basics-archive-497w.vercel.app/tictactoe-game/index.html) |
| 🐍 **Snake Game** | The classic Snake Game recreated using JavaScript and the HTML5 Canvas API. Move, grow, and try not to hit the walls or yourself! | [Play Here](https://javascript-basics-archive-497w.vercel.app/Snake-Game/index.html) |
| ✊ **Rock Paper Scissors** | A fun mini-game where you play against the computer. It randomly generates moves and keeps score dynamically. | [Play Here](https://javascript-basics-archive-497w.vercel.app/rock-paper-scissors/index.html) |
