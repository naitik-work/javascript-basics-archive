# Niccolò Miranda Portfolio UI Clone

This project is a **UI clone of [Niccolò Miranda’s portfolio website](https://www.niccolomiranda.com/)**, built with **HTML, CSS, JavaScript, GSAP, and Locomotive Scroll**.
The idea behind this project was not just to replicate a visually creative website, but also to practice and strengthen my front-end development skills — especially around **animations, smooth scrolling, and responsive layouts**.

## ✨ What this project is about

* Rebuilt the **look and feel** of Niccolò Miranda’s portfolio site.
* Explored **GSAP** for advanced animations and transitions.
* Implemented **Locomotive Scroll** for smooth scrolling and parallax-like effects.
* Focused on making the design **responsive** across devices.
* Treated it as a **learning-by-doing project** to improve my eye for design and interactions.

## 🛠️ Tech Stack

* **HTML5** – structure
* **CSS3** – styling and responsiveness
* **JavaScript (ES6)** – interactivity
* **GSAP** – animations and transitions
* **Locomotive Scroll** – smooth scrolling experience
